PRACTICAL / SKILL-01
Process Creation and Command Execution

--------------------------------------------------
EXECUTION 1
--------------------------------------------------

Command entered:
ls

Output:
program
program.c

Process Information:
The parent process creates a child process using fork().
The child process executes the ls command using execlp().
The parent process waits for the child process using wait().

--------------------------------------------------
EXECUTION 2
--------------------------------------------------

Command entered:
pwd

Output:
/Users/kasturi/Desktop/OSSP/2520030070_Practical/src

Process Information:
The parent and child processes have different PIDs.
The child process executes the command and the parent waits
until the child process completes.

--------------------------------------------------
SYSTEM CALLS USED
--------------------------------------------------

fork()  - Creates a child process.
execlp() - Executes the entered command.
wait()  - Makes the parent wait for the child process.
getpid() - Displays the current process ID.
getppid() - Displays the parent process ID.

--------------------------------------------------
RESULT
--------------------------------------------------

The program successfully demonstrates process creation,
command execution and parent-child process synchronization.
