PRACTICAL 2

Title:
File Copying Using open(), read(), write(), and close()

Objective:
To develop a C program that copies the contents of one file to another using 
the system calls open(), read(), write(), and close(). The practical also 
demonstrates the transition between user space and kernel space and analyzes 
system calls generated by the cat command using strace.

Requirements:
1. Linux operating system
2. GCC compiler
3. Terminal
4. strace utility

System Calls Used:

1. open()
   Opens the source and destination files and returns file descriptors.

2. read()
   Reads data from the source file through the kernel.

3. write()
   Writes the data to the destination file through the kernel.

4. close()
   Closes the file descriptors after the copy operation.

Program Execution:
The program accepts two command-line arguments:
1. Source file
2. Destination file

Example:
./file_copy sample.txt copied.txt

Expected Output:
File copied successfully from sample.txt to copied.txt

User Space and Kernel Space Transition:

The C program executes initially in user space. When open(), read(), write(), 
or close() is called, control transitions from the user-space program to the 
kernel through a system call interface.

The kernel performs the requested operation using operating system services 
and hardware resources. After completing the operation, the kernel returns the 
result to the user-space program.

Execution Flow:

User Program
     |
     v
System Call
     |
     v
Kernel Space
     |
     v
File System / Storage Device
     |
     v
Kernel returns result
     |
     v
User Space

strace Analysis:

The strace utility is used in Linux to trace system calls generated by a 
process.

Command:
strace cat sample.txt

Important system calls expected during execution include:

1. execve()
   Starts the cat program.

2. openat()
   Opens sample.txt.

3. read()
   Reads data from the file.

4. write()
   Writes file contents to standard output.

5. close()
   Closes the file descriptor.

6. exit_group()
   Terminates the process.

System Call Sequence:

execve()
    ↓
openat()
    ↓
read()
    ↓
write()
    ↓
close()
    ↓
exit_group()

Kernel Services Involved:

execve() - Process execution
openat() - File system access
read() - Reading data from storage
write() - Writing data to terminal
close() - File descriptor management
exit_group() - Process termination

Conclusion:

The practical demonstrates how a user-space C program interacts with kernel 
services through system calls. The open(), read(), write(), and close() system 
calls provide controlled access to files. The strace utility helps observe the 
system-call sequence and understand how Linux provides file and process 
services to applications.
